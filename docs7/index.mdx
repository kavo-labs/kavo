## Stop writing repetitive CRUD endpoints

A hand-written Nest controller for one entity runs to about 77 lines and still has no pagination, filtering, sorting, or field selection. With Kavo it is three lines, and all of that is included:

```ts
@Kavo(Book)
@Controller("books")
export class BooksController {}
```

## The query grammar, on the wire

Filtering, sorting, pagination, and includes are all driven by the query string. No extra code to write.

<CodeGroup>
```http Filter & sort
GET /books
  ?filter[status][eq]=published
  &filter[publishedAt][gte]=2020-01-01
  &sort=-publishedAt
  &include=author
  &limit=2
```
```http Includes
GET /books/42
  ?include=author,reviews.user
```
```http Field selection
GET /books
  ?select=id,title,status
  &select[author]=id,name
```
```http Pagination
GET /books
  ?sort=title
  &limit=25
  &offset=50
```
```http Soft delete
GET /books
  ?withDeleted=true
  &filter[status][eq]=archived
```
</CodeGroup>
